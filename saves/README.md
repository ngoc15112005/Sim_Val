# Thư Mục Lưu Trữ Save Game (Sim_Val Saves Hub)

Thư mục này được tổ chức thành 2 kho lưu trữ riêng biệt theo từng chế độ chơi:

- **`saves/single/`**: Chứa toàn bộ các file sao lưu (`.json`) của **Chế độ Giải Đấu Đơn Lẻ** (VCT Kickoff, Masters, Champions lẻ).
- **`saves/campaign/`**: Chứa toàn bộ các file sao lưu (`.json`) của **Chế độ Cốt Truyện / Mùa Giải Liên Tục** (VCT Multi-Year Circuit, Hall of Fame, Storylines).

---

### Mẹo Sử Dụng:
1. Khi bạn bấm **Xuất Save Game** trong game, một bản sao `.json` sẽ tự động được sao lưu an toàn vào đúng thư mục này.
2. Bạn có thể copy các file save sang máy tính khác hoặc lưu trữ lên Google Drive / USB để không bao giờ lo mất dữ liệu!
